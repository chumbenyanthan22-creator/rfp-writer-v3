# 🧠 RFP Writer Pro

AI-powered RFP proposal generator with 6 AI Agents + Second Brain

## Features

- 🧠 Second Brain AI - Neural network visualization
- 🤖 6 AI Agents - Compliance, Writer, Pricing, Research, Quality, Legal
- 🌍 25+ Languages support
- 💰 Razorpay Payments integration
- 🔐 Supabase Authentication
- 📁 File Upload (PDF, DOCX, TXT)
- 📊 Bid Tracker
- 📚 Template Library

## Tech Stack

- **Backend**: Python Flask
- **AI**: Deepseek API
- **Database**: Supabase
- **Payments**: Razorpay
- **Frontend**: HTML/CSS/JavaScript
- **Deployment**: Vercel
